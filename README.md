# BioAulas

Site institucional da BioAulas — Professora Fabiele Pires.

## Arquivos
- `index.html` — página principal
- `style.css` — estilos responsivos e tema claro/escuro
- `script.js` — menu mobile, tema e formulário demonstrativo

## Publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `bioaulas`.
2. Envie os três arquivos (`index.html`, `style.css` e `script.js`) para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde a publicação. O GitHub mostrará o endereço do site.
